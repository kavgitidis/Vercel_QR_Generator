# 📍 KaiGamwTaQR - Feature Suite

A high-end, professional web application designed for creating aesthetic and brand-aligned Google Maps QR codes.

## 🎨 Visual Design & UI/UX
*   **Glassmorphism Interface:** A modern "frosted glass" aesthetic with deep backdrop blurs and subtle translucent borders.
*   **Dynamic Mesh Background:** An animated, multi-layered radial gradient background using the Catppuccin Mocha palette.
*   **Dual-Pane Workspace:** Focused sidebar for configuration and an expansive "Stage" for immersive live previews.
*   **Real-Time Rendering:** Instant feedback loop; the QR code updates automatically as you change any setting.
*   **Responsive Architecture:** Optimized for desktop precision and seamless mobile usage.

## 🛠️ QR Generation Features
*   **Google Maps Integration:** Specifically optimized for standard and short Google Maps URLs.
*   **Center Overlays (Priority-Based):**
    *   **Custom Emoji:** Ability to place any emoji in the center of the QR code.
    *   **Brand Logo Upload:** Support for custom PNG/JPG/SVG logos with transparency support.
*   **Isolation Logic:** Toggle-able "Clear Center" feature that removes QR modules behind the logo/emoji for a clean, professional look.

## 💎 Advanced Styling Suite
*   **Pixel (Matrix) Customization:**
    *   **Sharp Square:** The classic, high-contrast look.
    *   **Modern Rounded:** Soft, continuous modules.
    *   **Circular Dots:** A trendy, minimalist dot-matrix style.
    *   **Classy Paths:** Elegant, interconnected liquid modules.
*   **Eye (Anchor) Customization:**
    *   **Rigid Square:** Traditional geometric corners.
    *   **Smooth Corner:** Modern, organic rounded eyes.
    *   **Circular Eye:** Perfect circles for a unique aesthetic.
*   **Color Engineering:**
    *   **Solid Tones:** Precise HEX color selection.
    *   **Linear Gradients:** 45-degree smooth transitions between primary and secondary colors.

## 📦 Professional Export Options
*   **Ultra-HD PNG:** High-resolution 1000x1000 pixel export for social media and digital use.
*   **SVG Vector:** Scalable Vector Graphics for professional print (billboards, business cards, signage).
*   **Direct Download:** One-click instant export functionality.

## 🛠️ Tech Stack
*   **Frontend:** React 18 + Vite
*   **Styling:** Tailwind CSS v4
*   **Icons:** Lucide React
*   **Engine:** qr-code-styling (Canvas/SVG Hybrid)
*   **Font:** Inter (High-legibility typeface)
